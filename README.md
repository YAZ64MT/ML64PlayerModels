# ML64PlayerModels
ModLoader64 models processed for use with the [Player Model Manager Filesystem Addon](thunderstore.io/c/zelda-64-recompiled/p/YAZMT/Player_Model_Manager_Filesystem_Addon/) (PMM_FS) mod for Zelda64: Recompiled.

This repo contains models extracted from .pak files stored in the current commit of the Z64-CustomPlayerModels submodule.

These extracted models have been slightly modified to add metadata for the Zelda64: Recompiled mod to use, (e.g. giving the model a display name in PMM).

Note that there are many near-duplicates, as these models were initially built specifically for Ocarina of Time or Majora's Mask. PMM_FS accepts models built for either game.

If you want the .zobj files for use with zzplayas, check the [Z64-CustomPlayerModels repo on HylianModding](https://github.com/hylian-modding/Z64-CustomPlayerModels).

Given that the extraction process was automated by a script, not every model has been extensively tested. If any model crashes the game or does not show up in the model manager, please open an [issue](https://github.com/YAZ64MT/ML64PlayerModels/issues).
